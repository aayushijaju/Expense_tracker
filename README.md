# Simple Expense Tracker

A beginner-friendly expense tracker made with HTML, CSS, and vanilla JavaScript.

## Features
- Add an expense name, amount, category, and date
- Automatically calculate total spending
- Filter expenses by category
- Delete one expense or clear all expenses
- Save data in the browser using `localStorage`

## How to run on a Mac
1. Unzip `expense-tracker.zip`.
2. Open the `expense-tracker` folder in Visual Studio Code.
3. Open `index.html` in a browser. You can double-click the file in Finder.
4. For a convenient development workflow, install the **Live Server** extension in VS Code, then right-click `index.html` and choose **Open with Live Server**.

No Node.js, database, or internet connection is required.

## Important
This is a simple demo. Expenses are stored only in the current browser on the current device. Clearing browser site data can remove them. There is no login or cloud synchronization.
